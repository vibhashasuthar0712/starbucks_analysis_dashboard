# ☕ Starbucks Analytics Dashboard

## 📌 Project Overview

This project presents an interactive Starbucks Analytics Dashboard built using **Microsoft Power BI**. It explores Starbucks data through visualizations, KPI cards, filters, and beverage-level analysis.

## 🎯 Project Objectives

- Analyze Starbucks' global presence.
- Explore beverage-related data.
- Identify the top 5 highest-caffeine beverages.
- Present key metrics through KPI cards.
- Make data exploration interactive using filters.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Data Visualization
- Data Analysis

## 📊 Dashboard Features

- **Global Presence:** Visual analysis of Starbucks' geographical distribution.
- **KPI Cards:** Highlights important metrics.
- **Beverage Analysis:** Explores coffee and beverage categories.
- **Top 5 Caffeine Analysis:** Focuses on beverages with the highest caffeine values.
- **Interactive Filters:** Enables users to explore different parts of the dataset.
